# Security Policy

## Supported Versions
We actively maintain and provide security patches for the latest release on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability
We take the security of this portfolio and its booking integrations seriously. If you discover a security vulnerability, please follow responsible disclosure guidelines:

1. **Do NOT open a public GitHub issue** describing the vulnerability.
2. Email full technical details and reproduction steps directly to:
   **arindamk53@gmail.com**
3. Include:
   - Description of the vulnerability and its potential impact.
   - Exact steps or proof-of-concept to reproduce the behavior safely.
   - Affected components, files, or endpoints.
   - Suggested mitigations (if known).

## Response Timeline
- **Initial Acknowledgment:** Within 24 hours.
- **Triage and Assessment:** Within 48 hours.
- **Remediation & Patch Deployment:** Critical vulnerabilities within 24 hours of triage; non-critical issues within 7 days.
